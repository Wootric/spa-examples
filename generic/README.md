# generic

This example demonstrates how to programmatically show and hide a Wootric survey on demand, using a framework-agnostic approach.

Since the SDK isn't designed for multiple `wootric('run')` calls, this approach reloads the SDK fresh each time to ensure proper reinitialization.

## Configuring and running
* Open `wootric-toggle-survey.html` with a browser.
* Update the `Account Token` with your account token.
* Click on "Show Survey" / "Hide Survey"
